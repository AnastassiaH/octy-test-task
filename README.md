# Coinlayer Currency Checker

A responsive and theme-aware currency exchange rate checker built with React and Zustand. This application allows users to fetch and view live currency exchange rates via the Coinlayer API, with support for switching between light and dark mode and searching for exchange rates by target currency code.

## 🌐 Overview

The app fetches exchange rates from Coinlayer API and displays them in a responsive grid. Users can input a currency code (like `USD`, `EUR`, etc.) to check current exchange rates with that currency as the target.

## 🧰 Tech Stack

- **React** (with TypeScript)
- **Vite** (for development and build)
- **Tailwind CSS** (for styling)
- **Zustand** (for state management)
- **Axios** (for HTTP requests)
- **PostCSS + Autoprefixer** (for CSS processing)
